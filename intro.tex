\section{Introduction}

Consider the following well-known function which maps
over elements of the list, written in Agda:

\begin{minted}{agda}
map : ∀ {A B : Set} → (A → B) → List A → List B
map f [] = []
map f (x ∷ xs) = f x ∷ map f xs
\end{minted}

Enjoying both composability of this function and
simplicity of its type, we would like to reuse its
definition as much as possible. Up to a certain level,
we would surely be able to do so: after all,
\texttt{map} is polymorphic in source and target types,
so we can instantiate it with whatever types we want.
However, were we to find a magic lamp with a
type-theoretical djinn inside, we would ask him to grant
us three wishes:

\begin{enumerate}
    \item Reuse \texttt{map} at higher universe levels,
        e.g., given a \textit{type operator}, map over
        \textit{list of types}:
        \[
            (\mathtt{Set}\to\mathtt{Set})\to
            \mathtt{List}\,\mathtt{Set}\to
            \mathtt{List}\,\mathtt{Set}
        \]
    \item Automagically obtain a proof of the free
        theorem for \texttt{map} -- that is, some term
        of type
        \begin{multline*}
            \forall A\,A'\,(Q:A\to A'\to\mathtt{Prop}),
            \forall B\,B'\,(R:B\to B'\to\mathtt{Prop}),
            \\
            \forall f\,f',\left(
                \forall x\,x',Q\,x\,x'\to
                R(f x)\left(f' x'\right)
            \right)\to\\
            \forall
                (\mathtt{xs}:\mathtt{List}\,A)
                (\mathtt{xs}':\mathtt{List}\,A'),
            Q^*\,\mathtt{xs}\,\mathtt{xs}'\to
            R^*(\mathtt{map}\,f\,\mathtt{xs})
                (\mathtt{map}\,f'\,\mathtt{xs}');
        \end{multline*}
    \item Given groupoids $A$ and $B$ and a functor
        $f: A \to B$, construct a functor
        $\mathtt{map}\;f$ between groupoids
        $\mathtt{List}\,A$ and $\mathtt{List}\,B$.
\end{enumerate}

The first wish is, of course, granted by adjusting the
definition and making it level-polymorphic. While the
theorem in the second wish already holds in systems
with parametricity, obtaining a proof \textit{inside}
the system without human input is only possible in type
systems where parametricity is internalized \cite{
Bernardy:Parametricity2010,
Altenkirch:Parametricity2024}. The last wish currently
has to be fulfilled manually (or with some
metaprogramming involved \cite{Nawrocki:Lean2026}),
albeit with a couple of list inductions: some to define
a groupoid instance for \texttt{List} and few more to
prove functoriality of \texttt{map}.

We suggest a different approach. Before tweaking the
definition of \texttt{map}, let's first remember all of
the metatheoretic power our type system already has.
Abovementioned parametricity of polymorphic definitions
is the first result that comes to mind; note that it is
obtained by specifying a \textit{relational
interpretation} of the typing judgement
\cite{reynolds1983types}. And indeed, ones of the most
interesting metatheoretic results can be expressed by
constructing a certain \textit{model} of a type system:
synthetic results in homotopy theory are based on
($(\infty, 1)$-)groupoid model of (homotopy) type theory
\cite{HofmannStreicher-Thegroupoidmodelref,
altenkirch:groupoids}; McBride's usage of displacement
for universe polymorphism \cite{McBride:Crude2011,
McBride:Crude2012} can be viewed as constructing a model
of a type system in higher universes of itself and then
interpreting displaced constructions in it. Then, all of
our wishes listed above could be granted by constructing
a suitable model of a type system \textit{inside} itself
(hence we call these \textit{internal models}) and then
instantiating \texttt{map} in it. Throughout the paper,
we'll call type systems with self-reinterpretation
capabilities \textit{reflective}.

\subsection{Contributions}

\begin{itemize}
    \item Our main goal is to construct an implementable
        reflective dependently typed system. Main
        difficulty in doing so arises from a certain
        no-go result discussed in section
        \ref{no-go-section} which forces us to limit the
        power of reinterpretation in order to keep type
        checking decidable.
    \item For ease of presentation, we first offer a
        reflective type system based on Hindley-Milner
        type system called HM-R (section \ref{HM-R}).
        We prove that HM-R is sound, conservative with
        respect to simply-typed lambda calculus and that
        global type inference is decidable (section
        \ref{HM-R-properties}).
    \item Building upon the insights gathered from
        developing HM-R, we're finally equipped to dive
        into reflective version of Martin-L\"of type
        theory dubbed MLTT-R (section \ref{MLTT-R}). We
        prove soundness and conservativity of MLTT-R as
        well (section \ref{MLTT-R-properties}).
    \item As intended, by virtue of reinterpretation,
        MLTT-R incorporates both a restricted form of
        universe polymorphism and external
        parametricity. And, of course, you can use
        MLTT-R as a system for synthetic mathematics
        with internal reuse of synthetic results
        (section \ref{MLTT-R-applications}).
\end{itemize}
